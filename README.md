# R3.-Crea-y-estiliza-formularios-con-HTML-y-CSS

# Registro de la Persona Usuaria

Mi trabajo para la clase de Programación web del lado del cliente, el reto es R3. Crea y estiliza formularios con HTML y CSS. donde demostramos el uso de HTMl y CSS en formularios.

## 📌 Descripción

La página presenta un diseño de formulario moderno y limpio que recopila datos personales esenciales. Cuenta con un fondo de pantalla adaptativo, campos interactivos con efectos visuales al ser seleccionados (`:focus`) y una sección de intereses alineada de forma horizontal.

El formulario está diseñado para ofrecer una experiencia de usuario fluida, utilizando colores contrastantes para destacar las acciones principales como el botón de registro.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3

## 📂 Estructura del proyecto

```text
├── index.html
├── style.css
└── background.jpg
```

## 🎯 Temas utilizados

* Estructura avanzada de formularios HTML
* Selectores e identificadores CSS (`#form-registro`, `#registro`)
* Pseudo-clases de estado (`:focus`, `:hover`)
* Diseño adaptable (`background-size: cover`)
* Alineación con Flexbox para elementos en fila (`flex-direction: row` con `gap`)
* Tipografías externas mediante Google Fonts ("Archivo Black")
